# NEXORA - Landing Page Responsive

## Description
NEXORA est une page d'accueil fictive pour une plateforme d'apprentissage du développement web.

## Technologies utilisées
- HTML5
- CSS3
- Bootstrap 5
- Flexbox
- CSS Grid
- Media Queries

## Fonctionnalités
- Barre de navigation
- Section principale
- Trois cartes de fonctionnalités
- Section à propos
- Pied de page
- Design responsive adapté aux ordinateurs, tablettes et téléphones

## Auteur
Projet réalisé dans le cadre d'un exercice de développement Front-End.
